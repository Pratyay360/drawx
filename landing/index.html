DrawX

Offline-first brainstorming and whiteboard app. Infinite canvas powered by Excalidraw, built with Tauri v2, React, and SQLite.

Download View on GitHub

Features

  • Offline-First All your sketches and notes are stored locally. No internet required.
  • Infinite Canvas Powered by Excalidraw for unlimited drawing space.
  • Cross-Platform Available on Windows, macOS, and Linux.
  • Fast & Lightweight Built with Tauri for minimal resource usage.
  • Theme Support Multiple built-in themes including Matcha, Neutral, Stone, and Y2K.
  • Auto-Updates Seamless updates through Tauri's updater.
